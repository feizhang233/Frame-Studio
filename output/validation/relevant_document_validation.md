# Relevant Document 有限元基准验证报告

## 1. 结论

在当前求解器声明的适用范围内（二维刚接框架、线弹性、小变形、Euler-Bernoulli 梁、等截面单元），没有发现数学模型的实质性错误。刚度矩阵、局部/全局坐标变换、总体组装、均布荷载的一致等效节点力、反力及局部端力恢复均通过教材例题验证。

教材给出的手算结果经过 3-4 位有效数字的中间舍入。当前求解器保留完整双精度，因此刚架例题与教材打印值存在约 0.1%-2.0% 的差异；误差方向和量级可由教材的中间舍入解释，不构成模型错误。

## 3. 数值对比

### 3.1 Example 4.6：均布荷载悬臂梁

采用 `E=210 GPa`、`I=8e-6 m^4`、`L=4 m`、`w=12 kN/m` 代入教材闭式解：

- 教材闭式解：`v_tip = -wL^4/(8EI) = -0.2285714286 m`。
- 求解器：`v_tip = -0.2285714286 m`。
- 教材闭式解：`phi_tip = -wL^3/(6EI) = -0.0761904762 rad`。
- 求解器：`phi_tip = -0.0761904762 rad`。
- 教材静力解：`R_y = wL = 48,000 N`，`M = wL^2/2 = 96,000 N*m`。
- 求解器：`R_y = 48,000 N`，`M = 96,000 N*m`。

相对误差处于浮点舍入量级（测试容差 `1e-12`）。这项验证直接覆盖均布荷载的一致等效节点力及反力恢复。

## 4. 独立数值检查

- 所有基准模型的总体刚度对称性残差为 0 或浮点舍入量级。
- 自由自由度平衡残差约为 `1e-14` 到 `1e-16`。
- 单元轴力、剪力和弯矩平衡的归一化残差约为 `1e-16`。
- 完整测试套件通过，新增 4 个 Relevant Document 回归测试。

平衡检查只能证明同一离散方程内部自洽，不能单独证明方程本身正确。本次加入教材闭式解和手算结果的外部基准，正是为了补上这一点。

## 5. 发现的适用范围与功能缺口

以下项目不是本次验证范围内的公式错误，但会限制可分析的问题：

1. **构件内部集中荷载没有直接输入类型。** Example 5.3 需要在荷载位置增加节点并拆分构件。建议未来增加一致等效节点力形式的 member point load。
2. **没有纯杆/桁架单元及端部释放。** `FrameElement` 要求 `I>0` 且节点为刚接，因此不能忠实复现第 3 章桁架例题或 Example 5.4 的杆-框架混合模型。不能用极小 `I` 代替铰接，因为这会引入病态矩阵和错误的物理约束。
3. **采用 Euler-Bernoulli 梁假设。** 横向剪切变形被忽略；对深梁、短粗构件或低剪切刚度材料，模型会系统性低估挠度。此类问题应使用 Timoshenko 梁单元。
4. **仅适用于线弹性、小位移静力。** 不包含几何非线性、材料非线性、屈曲、动力和二阶效应。
5. **单元内位移曲线仍是有限元插值。** Example 4.6 的端点位移对单单元是精确的，但均布荷载下真实挠曲线为四次函数，而当前单元内横向位移为三次 Hermite 插值。需要细化网格来提高构件内部挠度精度；剪力和弯矩场已通过平衡方程保留分布荷载效应。
